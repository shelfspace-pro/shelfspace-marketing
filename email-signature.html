How to add this to Gmail:
  1. Click Copy signature under the one you want (or drag-select the signature and press Cmd+C — Cmd+A won't work)
  2. Go to Gmail → Settings → See all settings → General → Signature
  3. Create new signature, then paste (Cmd+V) into the editor
  4. Scroll to the bottom and click Save Changes
If the logo shows as a broken image: you pasted an older copy that embedded the logo as base64 data. Gmail strips those. Re-copy from this page — the logo now loads from https://shelfspace.pro/email/signature-mark.png.
